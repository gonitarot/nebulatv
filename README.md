# Lumi

Configuración cifrada de **Lumi** (app de TV). `data/config.enc.json` guarda tus addons y tu clave de TorBox cifrados con tu contraseña (AES-GCM + PBKDF2).

- Panel web (docs/): añade, ordena y activa addons.
- La app Lumi los descarga y descifra con tu contraseña, y sincroniza sola al abrir.
